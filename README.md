# Audio Denoising: Classical vs. Lightweight ML Methods
A comparison of classical signal processing and lightweight machine learning
approaches for speech enhancement, using the VoiceBank+DEMAND dataset.

## Project Overview
This project investigates how classical methods (spectral subtraction, geometric
spectral subtraction) compare to lightweight ML models (MLP, U-Net) in terms of
denoising performance and computational cost. All methods operate on
spectrogram-based representations of audio and are served via a REST API.

## Setup

### Quick Start — Run the API (no dataset required)

### 1. Clone the repository
```bash
git clone https://github.com/MordoTheHacker/Applied-ML-Audio-Denoising-RUG-2026
cd Applied-ML-Audio-Denoising-RUG-2026
```

### 2. Create and activate a virtual environment
```bash
python -m venv venv
# Mac/Linux
source venv/bin/activate
# Windows
venv\Scripts\activate
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
```

## Launching the API

```bash
uvicorn src.api:app --reload
```

The API will be available at:
- **API base**: http://localhost:8000
- **Interactive docs (Swagger UI)**: http://localhost:8000/docs
- **Alternative docs (ReDoc)**: http://localhost:8000/redoc

## Using the API

### Enhance a noisy audio file
```bash
curl.exe -X POST "http://localhost:8000/enhance?model=mlp" \
  -F "file=@path/to/noisy.wav" \
  -o enhanced.wav -v
```

Available models: `spectral_subtraction`, `geometric_subtraction`, `mlp`, `unet`

### Evaluate enhancement quality (requires clean reference)
```bash
curl.exe -X POST "http://localhost:8000/evaluate?model=mlp" \
  -F "noisy_file=@path/to/noisy.wav" \
  -F "clean_file=@path/to/clean.wav"
```

### List available models
```bash
curl http://localhost:8000/models
```

## Running Tests

pytest tests/test_api.py -v

---

### Full Setup — Retrain Models from Scratch

Only needed if you want to retrain the models yourself.

### 1. Download the dataset:
```bash
python src/data.py
```
This downloads VoiceBank+DEMAND into `data/raw/wavs/` (~10GB, may take a while).

### 2. Preprocess the dataset:
```bash
python src/preprocess.py
```
This segments the raw waveforms into 2-second chunks, applies STFT, and saves
log-magnitude spectrograms to `data/processed/train_spectrograms.npz` and
`data/processed/test_spectrograms.npz`. This step is memory-intensive and may
take 30+ minutes depending on your hardware.

### 3. Train the models:
```bash
python src/models/mlp.py
python src/models/unet.py
```
Or on a SLURM cluster:
```bash
sbatch scripts/run_mlp.sh
sbatch scripts/run_unet.sh
```

The classical models (spectral subtraction, geometric spectral subtraction)
require no training and are always available.

## Evaluation
Models are evaluated using the standard VoiceBank+DEMAND metrics:
- **PESQ** — Perceptual speech quality (-0.5 to 4.5, higher is better)
- **STOI** — Speech intelligibility (0 to 1, higher is better)
- **CSIG / CBAK / COVL** — Composite quality measures
- **SSNR** — Segmental signal-to-noise ratio (dB)
- **SI-SDR** — Scale-invariant signal-to-distortion ratio (dB)

## Docker Deployment

The API can also be run inside a Docker container for a fully isolated and reproducible environment. This avoids the need to manually install Python dependencies or system libraries such as `ffmpeg` and `libsndfile`.

### 1. Build the Docker image

```bash
docker compose build
```

### 2. Run the container
```bash
docker compose up
```

### 3. Acess the API
Once the container is running, the API will be available at:

- API base: http://localhost:8000

- Swagger UI: http://localhost:8000/docs

- ReDoc: http://localhost:8000/redoc

### 4. Stop the container
```bash
docker compose down
```
